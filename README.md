# Projects
A collection of robust Core Java applications focusing on database integration, object-oriented programming, and complex algorithm validation. Includes a Hospital Management System and a Calendar too.
<br>
About This Repository
This repository showcases console-based Java applications demonstrating backend logic, database management, and robust data validation. As a Certified Software Development Engineer in Test (SDET), these projects reflect a strong focus on quality-driven code and stable application architecture.
Included Projects:
Hospital Management System : A console-based application developed in Core Java to efficiently manage patient records, doctor information, and appointments. It features MySQL database integration via JDBC for full CRUD operations and utilizes SQL Joins for data retrieval. The modular codebase is built on OOP principles like Inheritance, Encapsulation, and Exception Handling.
Java Calendar Validation Tool : A utility designed to determine the exact 'Day of the Week' for any historical or future date. It incorporates a complex algorithm to handle Leap Year logic and edge cases like 'Feb 29' , backed by optimized input validation loops to prevent invalid entries and ensure stability.
